# First messages and time-up messages

The platform lets each language have its own first message, while both languages share one system prompt. The tutor works out whether it is in Hindi mode or English mode from the first message it said.

## First message

**Hindi (the default language)**

```
नमस्ते! मैं आपका Job-Ready English tutor हूँ। पाँच मिनट में हम आपकी job के पाँच English words practice करेंगे। बताइए, आप किस job की तैयारी कर रहे हैं?
```

In English: "Hello! I'm your Job-Ready English tutor. In five minutes we'll practise five English words for your job. Tell me, which job are you preparing for?"

**English**

```
Hi! I'm your Job-Ready English tutor. In five minutes, we'll practise five English words for your job. Which job are you preparing for?
```

## Time-up message

Said if a session reaches the 7-minute limit before the tutor has said goodbye.

**Hindi**

```
आज का time पूरा हो गया। बहुत अच्छी practice की! Well done, see you next time.
```

**English**

```
Today's time is up. Well done for practising, and see you next time!
```

## Why the Hindi is written this way

Hindi words are written in Devanagari and English words in English letters. The voice reads each script with its own pronunciation, so English work words such as "escalate" or "refund" don't come out with Hindi sounds.
